# 講師・教材管理者ガイド

[README](../README.md) · [受講者の準備](setup.md) · [本編](handson.md)

## 研修前

- この教材一式を配布元リポジトリの main に公開してください。空のリポジトリは Import できません。
- 受講者は独立したリポジトリを作ります。共用リポジトリへの書き込み権限や別のレビュー用アカウントは不要です。
- 対象は Windows の WSL2 Ubuntu。Git・gh・uv・AI CLI・Node.js は Ubuntu 内で使える状態にします。
- GitHub と AI ツールのアカウント・認証、組織の利用可否を事前に確認します。環境準備は本編90分の外で行います。
- 自分の研修用リポジトリで Issues と Actions を有効にし、承認を必須にしない構成にします。
- Claude Code / Codex のどちらでも、Skills 候補と Issue の取得を事前に確認してください。

外部 Skills の配置や挙動は更新されます。研修直前に
[公式 README](https://github.com/mattpocock/skills)と導入コマンドを確認してください。
教材では必要な Skills をファイル方式で導入するため、プラグインとの二重導入は避けます。
同じ研修回では Skills の更新を途中で行わず、開始時の導入状態で進めてください。

## 教える際のポイント

Issue・ブランチ・Commit・Push・PR の各段階で、現在の状態がローカルと GitHub のどちらにあるかを問いかけます。
特に「Commit だけでは GitHub へ送られない」「PR 作成だけでは main に入らない」を実画面で確認します。

AI に任せる部分は、テスト・実装・コードレビューです。
Issue 起票、ブランチ作成、Commit・Push、PR、レビューの投稿、マージは受講者自身に操作してもらいます。
`implement` は標準で Commit するため、研修用の上書き指示が入っていることを確認します。

一人二役のレビューは「実装した人がもう一度コードを読む練習」です。
実務での他者レビューの代替にはしませんが、この研修の完了に他者の承認は要求しません。
良い点だけの場合も、どの条件をどのテストで確認したかをコメントに残してもらいます。

## 完了の判定

| 証拠 | 判定内容 |
| --- | --- |
| Issue | 背景・受け入れ条件があり、Closed になっている |
| PR 本文 | 実際の Issue 番号、変更理由、実行したテスト結果がある |
| Files changed | 割り算と対応するテストが追加され、不要なファイルがない |
| Checks | Tests / pytest が成功している |
| Review | Comment 形式のレビューがあり、指摘があれば対応している |
| ローカル main | Pull 後もテストと動作例が成功する |

初期テストは12件です。割り算テストの書き方により、演習後の件数は異なります。
パラメータ化、`pytest.approx`、`pytest.raises` の使い方より、Issue の振る舞いを検証できているかを優先します。
本編では pytest だけを必須にし、型検査や lint の追加で初学者の作業を増やさない構成です。

## 教材の保守・検証

WSL2 Ubuntu のリポジトリルートで実行します。

```bash
uv python install
uv sync --locked
uv run --locked pytest
uv run --locked python -c 'from calculator import add; print(add(2, 3))'
```

初期状態は12件成功、出力は `5` です。CI も同じ Python 系列とコマンドを使います。
テスト依存を更新する場合は uv で `uv.lock` を更新し、初期状態と演習の両方を再確認してください。

演習の検証は配布元を直接変更せず、一時コピーで実施します。
割り算テストを追加した段階で失敗し、実装後に通常値・小数・正負・分子ゼロ・ゼロ除算と既存テストが成功することを確認します。
完成コードを教材の main に混ぜると演習が成立しないので、解答は配布元へ反映しません。

公開後は独立した検証用リポジトリで、Import、Skills 設定、Issue、PR、CI、Comment レビュー、マージと Issue 自動クローズを一度通してください。
ローカルのテストだけでは GitHub の権限や画面操作の検証まではできません。

再受講する場合は新しいリポジトリ名で教材からコピーし直します。
すでに割り算をマージしたリポジトリを force push などで巻き戻す必要はありません。
